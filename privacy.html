Privacy policy

Last updated: October 2, 2026

What Reel accesses

With the signed-in user's permission, Reel reads Google Drive file metadata (names, folders, sizes, dimensions, durations, thumbnails) and the content of image and video files, using the read-only drive.readonly scope.

How the data is used

The data is used only to display the user's own media back to that same user in the Reel player. Reel does not use Google user data for advertising, analytics, profiling or training of any kind.

Where the data is stored

Reel runs on a computer owned by its user, on their home network. The OAuth token, the media index and a size-limited cache of thumbnails and video segments are stored only on that computer. Viewing history used to order the feed (for example which items were watched, favorited or hidden) is also stored only there. Nothing is sent to the developer or to any third-party server; the only external service Reel contacts is Google's own Drive API.

Sharing

Reel does not sell, share or transfer Google user data to anyone.

Retention and deletion

Cached files are evicted automatically as the cache fills. All stored data can be removed by deleting Reel's data folder, and access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Reel's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions can be raised through this project's GitHub issues.
